**LEIA ANTES DE EXECUTAR O .bat**



1. Extraia o relatório **FPRE111** do **SENIOR** no formato **CSV**
2. Renomeie no padrão **FPRE111-DDMMYYYY** e inclua na pasta **IMPORT** na área de trabalho
3. Execute o **ImportarUsuariosUmuarama.py** na maquina local
4. **DOUBLE CHECK** - Verifique a padronização dos cargos, departamentos, unidades, superior imediato
5. Importe para a INTRANET utilizando os seguintes campos:
   * Identificador: **CPF** 
   * E-mail: **padrão**
   * Inativar: **padrão**
   * Data: **Português Brasil (dd/mm/aaaa)**
   * Senha: **123mudar**
   * Primeiro acesso: **Solicitar alterar senha**
